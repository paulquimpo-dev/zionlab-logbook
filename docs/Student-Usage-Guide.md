# Student Usage Guide

Open the LZDS Logbook shortcut on your laboratory computer. Confirm the assigned PC number matches the label on that computer. Enter your first name, last name, grade, subject and reason. Student ID is optional. Choose Other to provide a short description. Select Check in once.

When finished, return to the logbook page and select **Check out now**. The server records the time. Do not close the browser in place of checking out. If the computer is unregistered or already has an active session, ask the laboratory administrator for help. Students do not need accounts and should never type a PC number or station credential.
